pra usar o openspec tem q entrar no diretório do seu projeto e digitar o comando ```openspec init``` 

_/opsx:_explore    Mapeia o problema e entende o código base

_/opsx:_propose    draft proposal.md, specs/, design.md, tasks.md

_/opsx:_apply    Implementa tarefas sobre a especificação

_/opsx:_verify    check the implementation matches the spec

_/opsx:_archive    archive completed changes
