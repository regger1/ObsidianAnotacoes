### No java temos 5 principais operadores de atribuição 

Atribuição Simples: [[#^exp-atrib-simples | =]]
Atribuição com Adição: [[#^exp-atrib-soma |+=]]
Atribuição com Subtração: [[#^exp-atrib-subtracao | -=]]
Atribuição com Multiplicação: [[#^exp-atrib-multiplicacao | *=]]
Atribuição com Divisão: [[#^exp-atrib-divisao | /=]]


A operação de atribuição simples serve para guardar um dado dentro de uma variável. Para realizar a ação de definir ou inicializar o valor de uma variável (recebe), utiliza-se do caractere **```=```**, onde o valor à direita é armazenado na variável à esquerda. ^exp-atrib-simples

Exemplo de código utilizando essa operação abaixo:
```Java
public class Main {
	public static void main(String[] args) {
	int numero = 10; // A variável "numero" recebe o valor 10
	
	System.out.println(numero); // retorna 10
	}
}
```


A operação de atribuição com adição serve para somar um valor à variável existeAdiçãonte e atualizar o seu resultado. Para realizar uma operação que pega o valor atual da variável e soma com outro (acrescenta), utiliza-se dos caracteres **```+=```**, funcionando como um atalho mais limpo e rápido na escrita. ^exp-atrib-soma

Exemplo de código utilizando essa operação abaixo:
```Java
public class Main {
	public static void main(String[] args) {
	int numero = 10;
	numero += 5; // É a mesma coisa que fazer: numero = numero + 5
	
	System.out.println(numero); // retorna 15
	}
}
```


A operação de atribuição com subtração serve para subtrair um valor da variável existente e atualizar o seu resultado. Para realizar uma operação que pega o valor atual da variável e diminui por outro (subtrai de), utiliza-se dos caracteres **```-=```**, sendo também um atalho direto. ^exp-atrib-subtracao

Exemplo de código utilizando essa operação abaixo:
```Java
public class Main {
	public static void main(String[] args) {
	int numero = 10;
	numero -= 4; // É a mesma coisa que fazer: numero = numero - 4
	
	System.out.println(numero); // retorna 6
	}
}
```


A operação de atribuição com multiplicação serve para multiplicar o valor da variável existente e atualizar o seu resultado. Para realizar uma operação que pega o valor atual da variável e o multiplica por outro (multiplica por), utiliza-se dos caracteres **```*=```**. ^exp-atrib-multiplicacao

Exemplo de código utilizando essa operação abaixo:
```Java
public class Main {
	public static void main(String[] args) {
	int numero = 10;
	numero *= 3; // É a mesma coisa que fazer: numero = numero * 3
	
	System.out.println(numero); // retorna 30
	}
}
```


A operação de atribuição com divisão serve para dividir o valor da variável existente e atualizar o seu resultado. Para realizar uma operação que pega o valor atual da variável e o divide por outro (divide por), utiliza-se dos caracteres **```/=```**. ^exp-atrib-divisao

Exemplo de código utilizando essa operação abaixo:
```Java
public class Main {
	public static void main(String[] args) {
	int numero = 10;
	numero /= 2; // É a mesma coisa que fazer: numero = numero / 2
	
	System.out.println(numero); // retorna 5
	}
}
```
