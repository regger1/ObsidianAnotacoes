### No java temos 4 operadores lógicos
E Lógico / AND:[[#^exp-and| &&]]
OU Lógico / OR: ||
NÃO Lógico / NOT: [[#^exp-nao | !]]
OU Exclusivo / XOR: [[#^exp-xor | ^]]


A operação E lógico (AND) serve para verificar se duas condições são verdadeiras simultaneamente. Para realizar uma operação onde ambas as condições precisam obrigatoriamente ser atendidas, utiliza-se dos caracteres **```&&```**, ele sempre retornará um booleano. ^exp-and

Exemplo de código utilizando essa operação abaixo:
```java
public class Main {
	public static void main(String[] args) {
	boolean condicao01 = true;
	boolean condicao02 = true;
	boolean condicao03 = false;
	
	System.out.println(condicao01 && condicao02); // retorna true
	System.out.println(condicao01 && condicao03); // retorna false
	}
}
```


A operação OU lógico (OR) serve para verificar se pelo menos uma de duas condições é verdadeira. Para realizar uma operação onde basta que apenas uma condição seja atendida, utiliza-se dos caracteres **```||```**, ele sempre retornará um booleano.

Exemplo de código utilizando essa operação abaixo:
```java
public class Main {
	public static void main(String[] args) {
	boolean condicao01 = true;
	boolean condicao02 = false;
	boolean condicao03 = false;
	
	System.out.println(condicao01 || condicao02); // retorna true
	System.out.println(condicao02 || condicao03); // retorna false
	}
}
```


A operação NÃO lógico (NOT) serve para inverter o valor de uma expressão ou variável booleana. Para realizar uma operação de negação do valor original (transformar true em false e vice-versa), utiliza-se do caractere **```!```**, ele sempre retornará um booleano. ^exp-not

Exemplo de código utilizando essa operação abaixo:
```java
public class Main {
	public static void main(String[] args) {
	boolean verdadeiro = true;
	boolean falso = false;
	
	System.out.println(!falso); // retorna true
	System.out.println(!verdadeiro); // retorna false
	}
}
```


A operação OU Exclusivo (XOR) serve para verificar se duas condições têm valores booleanos diferentes. Para realizar uma operação onde as condições devem ser estritamente opostas (apenas uma verdadeira e a outra falsa), utiliza-se do caractere **```^```**, ele sempre retornará um booleano. ^exp-xor

Exemplo de código utilizando essa operação abaixo:
```java
public class Main {
	public static void main(String[] args) {
	boolean condicao01 = true;
	boolean condicao02 = false;
	boolean condicao03 = true;
	
	System.out.println(condicao01 ^ condicao02); // retorna true (são diferentes)
	System.out.println(condicao01 ^ condicao03); // retorna false (são iguais)
	}
}
```
