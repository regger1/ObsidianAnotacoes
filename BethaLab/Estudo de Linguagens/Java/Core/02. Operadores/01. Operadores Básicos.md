### No java temos 4 operadores básicos
Soma:[[#^exp-soma | +]]
Subtração: [[#^exp-subtracao | -]]
Divisão: [[#^exp-divisao | /]] 
Multiplicação: [[#^exp-multiplicacao | *]]

Para realizar uma operação de soma, utiliza-se do caractere **```+```** ^exp-soma

Exemplo de código utilizando essa operação abaixo:
```java
Public class Main {
	public static void main(String[] args) {
	int numero01 = 10;
	int numero02 = 20;
	
	System.out.println(numero01 + numero02); // retorna 30
	}
}
```

Para realizar uma operação de subtração, utiliza-se do caractere **```-```** ^exp-subtracao

Exemplo de código utilizando essa operação abaixo:
```java
Public class Main {
	public static void main(String[] args) {
	int numero01 = 10;
	int numero02 = 20;
	
	System.out.println(numero01 - numero02); // retorna -10
	}
}
```

Para realizar uma operação de divisão, utiliza-se do caractere **```/```** ^exp-divisao

Exemplo de código utilizando essa operação abaixo:
```java
Public class Main {
	public static void main(String[] args) {
	int numero01 = 10;
	int numero02 = 20;
	
	System.out.println(numero02 / numero01); // retorna 2
	}
}
```

Para realizar uma operação de multiplicação, utiliza-se do caractere **```*```** ^exp-multiplicacao

Exemplo de código utilizando essa operação abaixo:
```java
Public class Main {
	public static void main(String[] args) {
	int numero01 = 10;
	int numero02 = 20;
	
	System.out.println(numero01 * numero02); // retorna 200
	}
}
```
