### No java temos 6 operadores relacionais
Igual a:[[#^exp-igual| ==]]
Diferente de: [[#^exp-diferente | !=]]
Maior que: [[#^exp-maior | >]] 
Menor que: [[#^exp-menor | <]]
Maior ou igual a: [[#^exp-maior-ou-igual | >=]]
Menor ou igual a: [[#^exp-menor-ou-igual | <=]]

A operação igual serve para comparar dois dados e verificar se eles tem valores iguais.
Para realizar uma operação de comparação de um valor pelo outro (igual a), utiliza-se dos caracteres **```==```**, ele sempre retornará um booleano. ^exp-igual

Exemplo de código utilizando essa operação abaixo:
```java
Public class Main {
	public static void main(String[] args) {
	int numero01 = 1;
	int numero02 = 1;
	int numero03 = 2;
	
	System.out.println(numero01 == numero02); // retorna true
	System.out.println(numero01 == numero03); // retorna false
	}
}
```

A operação diferente serve para comparar dois dados e verificar se eles tem valores diferentes.
Para realizar uma operação de diferente, utiliza-se dos caracteres **```!=```**, ele sempre retornará um booleano. ^exp-diferente

Exemplo de código utilizando essa operação abaixo:
```java
Public class Main {
	public static void main(String[] args) {
```

A operação maior serve para comparar dois dados e verificar se o primeiro valor é maior que o segundo.
Para realizar uma operação de comparação de maior, utiliza-se do caractere **```>```**, ele sempre retornará um booleano. ^exp-maior

Exemplo de código utilizando essa operação abaixo:
```java
Public class Main {
	public static void main(String[] args) {
	System.out.println(1 > 2); // retorna false
	System.out.println(2 > 1); // retorna true
	System.out.println(2 > 2); // retorna false
	}
}
```

A operação menor serve para comparar dois dados e verificar se o primeiro valor é menor que o segundo.
Para realizar uma operação de comparação de menor que, utiliza-se do caractere **```<```**, ele sempre retornará um booleano. ^exp-menor

Exemplo de código utilizando essa operação abaixo:maior
```java
Public class Main {
	public static void main(String[] args) {
	System.out.println(1 < 2); // retorna false
	System.out.println(2 < 1); // retorna true
	System.out.println(1 < 1); // retorna false
	}
}
```

A operação maior ou igual serve para comparar dois dados e verificar se o primeiro valor é maior ou igual ao segundo.
Para realizar uma operação de comparação de maior ou igual, utiliza-se dos caracteres **```>=```**, ele sempre retornará um booleano. ^exp-maior-ou-igual

Exemplo de código utilizando essa operação abaixo:
```java
Public class Main {
	public static void main(String[] args) {
	System.out.println(2 >= 1); // retorna true
	System.out.println(2 >= 3); // retorna false
	System.out.println(2 >= 2); // retorna true
	}
}
```
