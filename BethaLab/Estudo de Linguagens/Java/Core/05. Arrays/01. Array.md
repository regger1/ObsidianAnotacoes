Um array é um objeto que pode caber mais de uma informação dentro dele, ele é um tipo de Referência.

abaixo a sintaxe pra declarar uma variável de array no java:
```Java
	int[] idades = new int[3]; //pra declarar a variavel deve-se declarar também o tamanho dele
	idades[0] = 21;
	idades[1] = 15;
	idades[2] = 11;
```

Ela pode ser de outros tipos tb, até mesmo String. 

```Java
	String[] nomes = new String[3];
	nomes[0] = "goku";
	nomes[0] = "vegeta";
	nomes[0] = "freeza";
	
	for(int i = 0; i < 3; i++){
	System.out.println("nomes[i]");
	/* retorno no terminal:
	goku
	vegeta
	freeza
	*/
	}
```

Como um array é um tipo de referência, ele possui comandos diferentes, como o .length, que vai pegar o tamanho do array, então no exemplo acima dava pra fazer o for da seguinte maneira:
```Java
	String[] nomes = new String[3];
	nomes[0] = "goku";
	nomes[0] = "vegeta";
	nomes[0] = "freeza";
	
	for(int i = 0; i < nomes.length; i++){
	System.out.println("nomes[i]");
	/* retorno no terminal:
	goku
	vegeta
	freeza
	*/
	}
```
