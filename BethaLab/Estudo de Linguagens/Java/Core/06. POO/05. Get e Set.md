Quando os atributos do objeto são **privados**, é necessário criar getters e setters pras variaveis que você deseja acessar, o **set** serve pra setar a variável e dizer que a variável que está no objeto será substituída pela variável (do mesmo tipo) enviada no parâmetro, já o **get** vai ser responsável por pegar essa variável modificada e retornar ao usuário.

Objeto com getters e setters:
```Java
	public class Pessoa {
		public String nome;
		public int idade;

		public void imprime() {
			System.out.println(this.nome);
			System.out.println(this.idade);
		}

  

		public void setNome(String nome) {
			this.nome = nome;
		}

  

		public void setIdade(int idade) {
			if (idade < 0) {
				System.out.println("idade invalida");
				return;
			}
			this.idade = idade;	
		}
		
		public String getNome() {
			return nome;
		}

		public int getIdade() {
			return idade;
		}
}
```


Classe chamando o objeto:
```Java
	public static void main(String[] args){
		Pessoa pessoa = new Pessoa();
		pessoa.setNome = ("João");
		pessoa.setIdade = (12);
		
		System.out.println(pessoa.getNome()); // retorna "João" pq foi setado e tem um get pra ele
		System.out.println(pessoa.getIdade()); // retorna "12" pq foi setado e tem um get pra ele
	}
```
