Métodos fazem uma função específica, não necessáriamente são obrigadas a me retornarem algum resultado.

No exemplo de maçã, o objeto maçã passa pro método cortar, a maçã fica em 2 pedaços, mas ela não precisa necessariamente retornar pra mim. Só serve mesmo pra executar uma ou mais funções específicas no código.

Método
```Java
public class Calculadora {

	public void somaDoisNumeros() {
		System.out.println(10 + 10);
	}
}
```

Nessa classe é chamado o método pelo calculadora.somaDoisNumeros();
```Java
	public class CalculadoraTest01
		
		public static void main(String[] args) {
			Calculadora calculadora = new Calculadora();
			calculadora.somaDoisNumeros();
		}
```
