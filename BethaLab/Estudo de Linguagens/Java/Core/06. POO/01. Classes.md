### Classes em POO são objetos, que podem conter vários tipos de dados como template. Geralmente é usado pra replicar funções da vida real.  Para acessar esses dados (preencher) é usado uma variável de referência desse tipo.

**Como funciona:** Primeiro é criado um objeto (classe) no pacote model ou entity.

```Java
	public Class Estudante {
		public String nome;
		public int idade;
		public char sexo;
		public boolean matriculado;
	}
```

Para preencher esses dados, cria uma nova classe em um pacote diferente. Nessa nova classe, é criado uma variável de referência.

```Java
	public static void main(String[] args) {
		Estudante estudante1 = new Estudante();
		estudante1.nome = "Goku";
		estudante1.idade = 25;
		estudante1.sexo = 'M';
		estudante.matriculado = true;
	}
```
