Uma classe enum é geralmente usada pra armazenar dados que são imutáveis dentro do código, onde deixam padronizado os dados e são case sensitive.

A sintaxe pra declarar um enum é assim:
```Java 
public enum TipoPagamento{
	DEBITO,
	CREDITO
}
```

Porém ela é uma classe que pode fazer mais que só declarar dados imutáveis, um exemplo é esse:
```Java
public enum TipoPagamento{
	DEBITO {
		@Override
		public double calcularDesconto(Double valor) {
			return valor * 0.1;
		}
	},
	CREDITO {
		@Override
		public double calcularDesconto(Double valor) {
			return valor * 0.05;
		}
	};
	// os métodos esperam um valor como parâmetro e devolvem um desconto baseado no dado escolhido. 
	
	// System.out.println(TipoPagamento.CREDITO.calcularDesconto(100)) 
	// vai retornar 5
	
	public abstract double calcularDesconto(double valor);
}
```
