
O polimorfismo tem como principal característica ter muitas formas, no caso é a capacidade de tratar objetos de classes diferentes e específicas como se fossem do mesmo tipo base
Uma única interface pode tomar múltiplas formas através das classes que a implementam.

A interface é criada para assumir um papel de esqueleto, ele define oq define ser feito, mas não tem a lógica dentro dele, ele meio que só dá o nome pros métodos.
Cria-se classes que implementam dessa interface. Pegam o método abstrato e escreve sua própria lógica específica.
Declara-se uma variável de referência do tipo da interface e cria uma referência ao objeto da classe. Isso permite que o sistema chame o método genérico, mas a execução real será a do objeto específico que está na memória.

## 💻 Exemplo em Código (Java)

```java
// 1. A Interface (O Esqueleto)
public interface Pagamento {
    void processar(); // Método abstrato (o "que" fazer)
}

// 2. As Implementações (As múltiplas formas)
public class PagamentoCartao implements Pagamento {
    @Override
    public void processar() {
        System.out.println("Processando pagamento via Cartão de Crédito...");
    }
}

public class PagamentoPix implements Pagamento {
    @Override
    public void processar() {
        System.out.println("Processando pagamento via Pix Instantâneo...");
    }
}

// 3. O Polimorfismo em Ação
public class Main {
    public static void main(String[] args) {
        // Variável de referência é a INTERFACE. O objeto é a CLASSE.
        Pagamento meuPagamento1 = new PagamentoCartao();
        Pagamento meuPagamento2 = new PagamentoPix();
        
        // O mesmo método se comporta de formas diferentes dependendo do objeto real!
        meuPagamento1.processar(); // Saída: Processando pagamento via Cartão...
        meuPagamento2.processar(); // Saída: Processando pagamento via Pix...
    }
}
