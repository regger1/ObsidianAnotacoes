Na criação de métodos, pode-se esperar de parâmetros para funcionar e executar o código dentro deles.

Para fazer com que um método espere um parâmetro, no Java funciona dessa forma:

Método:
```Java
public class Calculadora() {
	public void multiplicaDoisNumeros(int num1, int num2)//esses são os parâmetros 
	{
		System.out.println (num1 * num2); // aqui é oque o método vai fazer com os parâmetros dados pelo usuário
	} 
}
```

Classe chamando o método:
```Java 
public class CalculadoraTeste() {
	public static void main (String[] args) {
		Calculadora calculadora = new Calculadora();
		calculadora.multiplicaDoisNumeros(10, 20) // aqui ele espera os números declarados nos parâmetros (num1, num2)
	} 
}
```
