Com o super eu consigo pegar tudo oq ta dentro do método da classe pai e colocar dentro da classe filho só dando o comando super antes de importar o método.

O comando super tem que obrigatoriamente ser na primeira linha do método.
```Java
	public void imprime(){
		super.imprimeDaClassePai(); // aqui ele vai herdar tudo do método imprimeDaClassePai
		System.out.println("Dentro da classe filho");
	}
	
	// retorno do terminal: 
	// Dentro da classe pai
	// Dentro da classe filho
```

método imprimeDaClassePai:
```Java
	public void imprimeDaClassePai() {
		System.out.println("Dentro da classe pai");
	}
```
