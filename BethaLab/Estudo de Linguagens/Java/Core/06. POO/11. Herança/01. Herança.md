Herança é basicamente tu herdar os atributos de uma classe Pai, algo parecido com isso é o sistema de Animais, onde um animal pode ser Mamífero, na classe mamífero podem se ter Canídeos, Felinos, dentro da classe felinos podem ter Leão, Gato e etc. A ideia é aproveitar dos atibutos das classes acima pra tu não precisar reescrever na mão tudo de novo.

Quando quer herdar uma classe pai, utiliza-se do **```extends```**.

Superclasse:
```Java
class Animal { 
	String nome; 
	public void emitirSom() {
		System.out.println("O animal faz um som."); 
	} 
}
```

Classe Filha:
```Java
class Cachorro extends Animal {
	// sobrescrevendo o método da classe mãe para um comportamento específico
	@Override
	public void emitirSom(){
		System.out.println("O cachorro late: au au!");
	}
	
	// Método exclusivo da classe filha
	public void abanarRabo() {
		System.out.println("O cachorro está abanando o rabo.");
	}
}
```

Classe principal para execução:
```Java
public class Main () {
	public static void main (String[] args) {
		Cachorro meuCachorro = new Cachorro();
		
		// O atributo "nome" foi herdado da classe Animal
		meuCachorro.nome = "Rex";
		System.out.println("Nome do Cachorro: "+meuCachorro.nome);
		
		// Chama o método que foi sobrescrito na classe Cachorro
		meuCachorro.emitirSom();
		
		// Chama o método específico da classe Cachorro
		meuCachorro.abanarRabo();
	}
}
```
