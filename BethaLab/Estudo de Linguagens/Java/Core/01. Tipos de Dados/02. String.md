### String é um tipo de dado usado na programação para representar textos, palavras e sequências de caracteres.

```java
Public class Main {
	public static void main(String[] args) {
	String nome = Goku;
	System.out.println(nome); // retorna "Goku"
	
	// caso queira fazer uma concatenação, no java é feito dessa forma:
	
	System.out.println("Oi, meu nome é"+nome+"!") // retorna "Oi, meu nome é Goku!
	}
}
```
