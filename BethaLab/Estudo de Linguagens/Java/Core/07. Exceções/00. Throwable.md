Throwable significa lançável, então quando o Throwable lança algo, pode ser tanto um error ou uma exceção.

Checked e Unchecked

* Exceções Checked são filhas da classe Exception, ocorrem em tempo de compilação
* Exceções Unchecked são quando fez algo errado no código
