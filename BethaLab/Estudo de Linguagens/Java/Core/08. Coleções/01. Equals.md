O método equals é herdado de Object e é utilizado pra comparar a referência de memória entre dois valores e retornar um booleano.

```Java
	String nome = "João";
	String nome2 = "João";
	
	System.out.println(nome.equals(nome2)); // retorna true
```

Porém, quando se faz dessa forma abaixo o equals retorna false:
```Java
public class Smartfone {
	private String serialNumber;
	private String marca;
	
	public Smartfone(String serialNumber, String marca) {
		this.serialNumber = serialNumber;
		this.marca = marca;
	}
	
	// get e set
}

-----------------------------------------------------------------

public class Teste {
	public static void main(String[] args) {
		Smartphone s1 = new Smartphone("1ABC1", "Iphone");
		Smartphone s2 = new Smartphone("1ABC1", "Iphone");
		
		System.out.println(s1.equals(s2));
		// mesmo que pareça ser true, vai ser retornado falso
	}
}
```
O motivo de dar falso é porque o equals() é um método extendido da classe Object, que compara referência de memória (dois ponteiros apontando pro mesmo objeto). Nesse caso, quando é dado duas vezes `new Smartfone` está sendo comparado em dois objetos diferentes.

Para isso, dá pra fazer tu mesmo a tua regra do método equals().
```Java
// Reflexivo: x.equals(x) tem que ser true pra tudo que for diferente de null

// Simétrico: para x e y diferentes de null, se x.equals(y) == true, logo
// y.equals(x) == true

// Transitividade: para x, y, z diferentes de null, se x.equals(y) == true, logo
// x.equals(z) == true, logo y.equals(z) == true

// Consistente: x.equals(x) sempre retorna true se x for diferente de null

// Para x diferente de nyll, x.equals(null) tem que retornar falso

// ---------------- dentro da classe Smartfone --------------

@Override
public boolean equals(Object obj) {
	if (obj == null)
		return false;
	if (this == obj)
		return true;
	if (this.getClass() != obj.getClass())
		return false;
	Smartphone smartphone = (Smartphone) obj;
	return serialNumber != null && serialNumber.equals(smartphone.serialNumber);
}
```
Aqui estamos mudando o comportamento do equals

* no primeiro if está vendo se obj é nulo, se for ele vai retornar falso obviamente
* no segundo if é comparado se this e obj são a mesma referencia (apontam pro mesmo objeto em memória)
* no terceiro if verifica se os dois objetos são da mesma classe
* ai pra ser true, é necessário que o serial number seja diferente de null e o serial number seja igual ao serialnumber do smartfone (no caso aqui ele so vai comparar se o serialNumber é o mesmo, independente de ser aparelhos diferentes)
