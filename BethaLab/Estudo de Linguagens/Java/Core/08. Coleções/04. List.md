A interface `List` (junto com sua implementação mais usada, o `ArrayList`) serve para criar arrays dinâmicos. Diferente de um array tradicional (`String[]`) que tem um tamanho fixo, a `List` é altamente incrementável.
Enquanto você vai adicionando elementos, ela faz toda a lógica de alocação de memória por debaixo dos panos sem que você precise se preocupar com isso.

```Java 
// A sintaxe diamond <> força a tipagem da lista (Generics).
// Isso garante segurança, não deixando você colocar um int em uma lista de String.
List<String> nomes = new ArrayList<>();
List<String> nomes2 = new ArrayList<>();
```

---

Por padrão, um `ArrayList` nasce com capacidade para 10 elementos. Quando esse limite é atingido, ele cria um novo array maior (aumentando cerca de 50% do tamanho atual) e copia os dados para lá automaticamente.

Para manipular os dados dentro dessa lista, existem vários métodos prontos:
```Java
nomes.add("Carlos");
nomes.add("João");

nomes2.add("Maria");

// Adiciona na lista 'nomes' todos os elementos que estão dentro de 'nomes2'
nomes.addAll(nomes2); 

// Formas de remover elementos:
nomes.remove("Carlos"); // Remove pelo objeto (usa o método equals() daquele objeto para achar a correspondência)
nomes.remove(1);        // Remove diretamente pelo índice numérico
```

---

Para percorrer (iterar) sobre uma lista, as duas formas mais comuns são o `for-each` e o `for` tradicional com índice:
```Java
// For-each: a variável de referência tem que ser do mesmo tipo definido no <> da List
for (String nome : nomes) {
    System.out.println(nome);
}

// For indexado: 
// Usa-se o nomes.size() para saber o tamanho (ao invés do .length dos arrays comuns)
for (int i = 0; i < nomes.size(); i++) {
    System.out.println(nomes.get(i)); // O .get(i) resgata o elemento daquela posição
}

// Imprimir a lista inteira de uma vez (chama o toString() padrão do ArrayList)
System.out.println(nomes); // Saída: [João, Maria]
```

Aqui estamos mudando a forma de interagir com os dados em relação ao Array comum:

- No lugar de `nomes[0]`, usamos `nomes.get(0)`.
- No lugar de `nomes.length`, usamos `nomes.size()`.

**Regra importante sobre Tipos Primitivos:** Coleções no Java (como a `List`) exigem objetos. Portanto, não é possível criar uma `List<int>` ou `List<double>`.

```Java
// É obrigatório usar as classes Wrapper (classes empacotadoras) para tipos primitivos
List<Integer> numeros = new ArrayList<>();
numeros.add(1); // O Java faz o Autoboxing (converte o int 1 para um objeto Integer automaticamente)
```
