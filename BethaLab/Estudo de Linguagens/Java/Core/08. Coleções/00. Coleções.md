### As coleções são um grupo de dados onde podem ser divididos em diferentes classes. Elas tem dois tipos de categorias, sendo elas Ordered e Sorted.

---

**Ordenado** é quando o java consegue lembrar dos elementos onde eles deveriam estar. Exemplo em um array, onde o java sabe como ordenar através das posições dos índices.

**Sortido** a iteração da ordem geralmente é baseado em algo que você mesmo predefiniu. Exemplo é quando tu quer sortear nomes com base na letra inicial, então tu força o java a ordenar os dados por essa ordem q tu estipulou pra ele.
