### O java tem 3 estruturas de repetição básicas:

[[#^exp-while|While]], [[#^exp-do-while |do-while]] e [[#^exp-for |for]]

Quando deseja-se sair do laço de repetição, usa o **```break```.**
E o contrário é com o comando **```continue```**

O **```while```** funciona de uma maneira bem simples, ele pede uma resposta booleana que deve ser atendida dentro do parênteses, enquanto não chega na resposta ele repete tudo que está dentro das chaves ^exp-while

Abaixo a sintaxe do while no java:

```Java
int count = 0;
while (count < 10)
{
	System.out.println(count++) // saída do terminal: 1, 2, 3, 4, ..., 9
}
```


O **```do while```** funciona de forma parecida, só que ele primeiro vai executar o código e depois analisar a condição dentro do while. Sempre vai executar pelo menos 1 vez o código independentemente do resultado dentro dos parênteses no while. ^exp-do-while

Sintaxe do do-while 
```Java
	do {
		System.out.println ("dentro do do-while");
	} while(count < 10);
	// aqui vai só printar a mensagem, mesmo não informando o count ele imprime a mensagem uma vez
```


O **```for```** é um pouco diferente, ele é dividido em 3 partes, a primeira é o incrementador, a segunda vc define até onde esse laço de repetição seja executado, e a terceira é como a variável vai alterar o status. ^exp-for

A sintaxe está abaixo:
```Java
for (int i=0; i < 10; i++) {
	System.out.println(i); // resultado: 1, 2, 3, 4, ... 
}
```
