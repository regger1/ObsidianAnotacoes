#### O else sempre vem acompanhado do [[01. IF]], ele significa CASO CONTRÁRIO, então é outra condicional pro if, podendo ser ativada quando o if não tem sua condição atendida.

Abaixo um exemplo do IF sendo usado em código:
```java
Public class Main {
	public static void main(String[] args) {
	int idade = 15;
	
	if (idade >= 18) {
		System.out.println("Pode beber"); // esse print seria ignorado e iria pular pro else 
	} else {
		// aqui ele vai aceitar entrada de números abaixo de 18
		System.out.println("pode nao!"); // entra no else
	}
	
}
```
