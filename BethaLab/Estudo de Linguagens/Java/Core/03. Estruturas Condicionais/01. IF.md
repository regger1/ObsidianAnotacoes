#### IF é uma das estruturas condicionais mais básicas da linguagem Java. Ela representa SE - ENTÃO, se uma informação for x, ela faz y. Ela analisa as informações dentro do parênteses ```()```, que sempre avalia uma condição lógica (verdadeira ou falsa) e executa as intruções/comandos que estão dentro chaves ```{}``` caso atenda as exigências estipuladas dentro dos parênteses.


Abaixo um exemplo do IF sendo usado em código:
```java
Public class Main {
	public static void main(String[] args) {
	int idade = 20;
	
	if (idade >= 18) {
		System.out.println("Pode beber"); // Entra no if
	}
	
	if (idade < 18) {
		System.out.println("não pode beber"); // não entra no if pq nao atende os requisitos dentro dos parenteses
	}
	
	if (idade > 20) {
		System.out.println("vc tem mais que 20 anos"); // não entra
	}
	
	if (idade >= 20) {
		System.out.println("vc tem mais 20 anos ou mais"); // entra
	}
}
```


Outras formas de usar o if é atribuindo valores em uma variável e colocando dentro do if pra fazer a verificação lógica:
```java
Public class Main {
	public static void main(String[] args) {
	
	idade = 15;
	boolean isPermitidoComprarBebida = idade >= 18;
	
	if (isPermitidoComprarBebida) {
		System.out.println("Pode comprar bebida"); // Não entra no if
	}
	
	if (!isPermitidoComprarBebida) {
		System.out.println("Não pode comprar bebida"); // Entra no if
	}

}
```
