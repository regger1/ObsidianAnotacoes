### No Java existem 8 tipos primitivos:
#### [[#^exp-int|int]], [[#^exp-double|double]], [[#^exp-float | float]], [[#^exp-char | char]], [[#^exp-byte | byte]], [[#^exp-short | short]], [[#^exp-long | long]], [[#^exp-boolean | boolean]]

**```int```** representa um número inteiro, cabe ```4 bytes``` na memória ^exp-int

Abaixo um exemplo de código utilizando esse tipo primitivo:
```java
Public class Main {
	public static void main(String[] args) {
	int idadeInt = 18; //atribui 18 à variável "idade"
	System.out.println(idadeInt); // retorna 18
	}
}
```

**```double```** representa um número grande, cabendo até ```8 bytes``` na memória ^exp-double

Abaixo um exemplo de código utilizando esse tipo primitivo:
```java
Public class Main {
	public static void main(String[] args) {
	double salarioDouble = 2500;
	System.out.println(salarioDouble); // retorna 2500
	}
}
```

**```float```** representa um número decimal, cabe até ```4 bytes``` na memória. ^exp-float

Abaixo um exemplo de código utilizando esse tipo primitivo:
```java
Public class Main {
	public static void main(String[] args) {
	float salarioFloat = 2500.5;
	System.out.println(salarioFloat); // retorna 2500
	}
}
```

**```char```** representa um caractere, cabe ```2 bytes``` na memória. ^exp-char

Abaixo um exemplo de código utilizando esse tipo primitivo:
```java
Public class Main {
	public static void main(String[] args) {
	char caractere = "a";
	System.out.println(caractere); // retorna "a"
	}
}
```

**```byte```** representa um número inteiro, cabe somente ```1 byte``` de memória, indo de um valor de -128 até 127. ^exp-byte

Abaixo um exemplo de código utilizando esse tipo primitivo:
```java
Public class Main {
	public static void main(String[] args) {
	byte idadeByte = 18; //nesse caso, se uma pessoa passar dos 127 anos a variável estoura o limite de memória.
	System.out.println(idadeByte);
	}
}
```

**```short```** representa um número inteiro, cabe ```2 bytes``` na memória. ^exp-short

Abaixo um exemplo de código utilizando esse tipo primitivo:
```java
Public class Main {
	public static void main(String[] args) {
	short idadeShort = 18;
	System.out.println(idadeShort);
	}
}
```

**```long```** representa um número muito grande, cabe ```8 bytes``` na memória. ^exp-long

Abaixo um exemplo de código utilizando esse tipo primitivo:
```java
Public class Main {
	public static void main(String[] args) {
	long numeroGrande = 100000;
	System.out.println(numeroGrande); //retorna 100000
	}
}
```

**```boolean```** representa um tipo de dado lógico que aceita somente dois valores: verdadeiro (true) ou falso (false), ```cabe 1 bit``` na memória. ^exp-boolean

Abaixo um exemplo de código utilizando esse tipo primitivo:
```java
Public class Main {
	public static void main(String[] args) {
	boolean falso = false;
	boolean verdadeiro = true;
	System.out.println(falso); // retorna false (0)
	System.out.println(verdadeiro); // retorna true (1)
	}
}
```
